# Rahul Dhamecha — Portfolio

React + TypeScript + Vite portfolio for Rahul Dhamecha.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Customize

Edit `src/App.tsx` for:
- About content
- Skills
- Projects
- Experience
- LinkedIn/GitHub links

Place your latest resume PDF at:

`public/Rahul-Dhamecha-Resume.pdf`

## Deploy

Push this repository to GitHub and connect it to Cloudflare Pages.

Build command:

`npm run build`

Build output directory:

`dist`
